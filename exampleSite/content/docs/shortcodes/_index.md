hugodoks ships nine Pico-flavored shortcodes for documentation pages. Every page in this section is a live demo — the rendered result first, the source right after.

To show literal shortcode syntax inside a code block (as these pages do), escape it: `{{</* hint info */>}}` renders as text instead of executing.
